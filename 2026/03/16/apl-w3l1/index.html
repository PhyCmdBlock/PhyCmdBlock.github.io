week3 lesson1

  • 字符可以作为整数参与运算
  • %操作的两个数字必须都是整型，放浮点数报错
  • %操作到底是什么：实际上，这是涉及到取模和取余的两种不同的概念。数学里的a mod b是取模,这个结果不允许为负数，-11 mod 3 = 1.python中%是取模。然而另一个则是取余，遵循的规律是a%b=a%(-b)、a%b=-(-a)%b，-11 % 3 = -2总结为余数要和被除数同符号,商要尽量向0靠。C/C++、Java都是取余。
  • /操作左右都是整数：整除操作，直接略掉小数。
  • 分析表达式就是去搞一下入栈出栈。
  • 表达式分析规则：
    如果即将入符号栈的符号是
  1. ①top优先级高于新符号②优先级相等，结合性都是左结合。
    则：先算之前的，算完再入新的符号
  2. ①top优先级低于新符号②优先级相等，结合性都是右结合。
    则：立刻入栈，继续往下。
    如果表达式已经结束，没有新的东西能进入数栈和符栈，则清理栈内元素，直接反复进行求值，算到最后数栈剩一个数字，符栈空，如果不是这样那么一定是语法错误。
  • 单次求值的含义：符栈出1个符号，这个运算符是n目运算符，则数栈出n个数字,分别为第n-1个操作数……第1个操作数。然后进行操作。操作得到一个值，压入数栈。
  • 括号的行为：当左括号(准备入栈的时候，优先级很高，为2级（基本上在常用的运算符之上），当括号进入了栈内后，优先级变成了最低，理解为不存在的19级（在所有运算符之下）。右括号)优先级最低，也是19级。但这个符号都用不着进栈，因为当他满足进栈条件的时候，top肯定是左括号，这个时候两者进行抵消，top的左括号此时弹出。
  • 进行算术运算（其他运算符不是这样），如果运算符的操作数的数据类型不是统一的，会自动进行转换，转为优先级更高的类型。char,unsigned char, short, unsigned short会经历整型提升，无论如何都会被提升到int才会参与运算（即便是两个char相加也会转换）。
  • 优先级表记法：长类型肯定在上面，浮点数肯定在整型上面，同长度unsigned在signed上面
  • 注：上方规则并不完全揭示编译器的行为。具体很复杂。
  • 自增自减：a++先用后加，++a先加后用。后缀左结合，前缀右结合，后缀优先级高于前缀。独立成句时前后缀等价。不能对常变量、字面量发生作用。一个表达式不要出现多次对同一个变量的自增自减。
  • 强制类型转换3种方法：(int)a int(a) static_cast<int>(a)结果上一样，实际上3种运作有区别，第3种最好。只读形式访问，临时转变。
  • 赋值运算符左右类型不同，则将右值转成左值类型后赋值。这里的转变就是第二周第二节课里的那些类型互转。
  • 再补充一个转换：浮点到整型的时候，直接舍去小数，并非四舍五入。整型到浮点的时候，整数精度不够补0；整数精度超出范围，要丢精度的时候，进行四舍五入。
  • float f = 1.2;报：“初始化”: 从“double”到“float”截断。所以应该写float f = 1.2f;让一开始的字面量就是一个float。
  • 赋值运算符、复合赋值运算符优先级16级（互相之间同级），右结合，优先级比常用算术符低，所以a+=1+2是先算1+2。值是左值。a=b=5,实际上是先运算b=5,b=5的结果是b，然后运算a=b,a也获得了b的值5。一个表达式不要出现多次对同一个变量的赋值。
  • 逗号(顺序求值运算符)表达式求值:优先级最低的运算符，18级，左结合。表达式1,表达式2,……,表达式n，其实就是一个一个算过来，每次逗号都选择了后一个结果。最终得到的结果是表达式n的值。
  • 表达式类型：意思就是最后一步运算是什么类型。b=(a=3*6,a/2):赋值表达式
