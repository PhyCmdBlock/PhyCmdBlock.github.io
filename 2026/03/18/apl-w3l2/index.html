week3 lesson2

  • 程序有3种基本结构：顺序、选择（分支、条件）、循环。选择（分支、条件）分为单分支和双分支（有else）结构。
  • 流程图：
    1. 圆角矩形：入口出口
    2. 平行四边形：输入输出
    3. 菱形：判断
    4. 矩形：执行
  • 有两种循环：当型循环(while)和直到型循环(do-while)。前者是做之前检查条件满足情况，后者是做之后检查条件满足情况（一定会做一次）。
  • 语句有4种类型：
  1. 定义/声明：定义变量
  2. 执行语句：
    • 控制语句，9种，控制程序运行流程的
    • 函数、对象
    • 表达式语句
  3. 空语句：单出一个分号
  4. 符合语句：用{…}组合的语句
  • cin、cout、<<、>>
    cin、cout都是对象。<<、>>此处是流插入、提取运算符，原来是位操作运算符，7级优先级，经过重载变成现在的功能。重载现在不学。cout << a;实际上是表达式语句。可以使用本周第一节课对表达式分析的方式进行解释。<<在cout对象和a变量之间进行运算。运算的值是cout对象本身。
    cout << a,b,c;实际上是一个逗号表达式，表达式的值是c，最终只会输出a的值。
  • 缓冲区
    cout被插入数据后，存储在缓冲区内，当满足条件（缓冲区满/endl/‘\n’/使用cout.flush();刷新）才会集中输出一次。Windows系统下对这个规则的遵守不如Linux规范。
    cin不会被直接提取数据，输入的数据会存储在缓冲区内，当满足条件（缓冲区满/‘\n’）才会集中被提取一轮数据。
  • 输入输出设备均可以更改，称为输入/输出重定向。（其实我不知道这是干嘛的）
  • 输出会自动判断数据类型，选择合适的方法输出。char类型会自动按照字符输出。如果想要按数字或者按字符输出，强制类型转换即可。
  • 奇技淫巧：不用强制类型转换，但是让char以整数的方式输出：cout << ch+0 << endl;整型提升
  • cin 不能把数据提取到常量、表达式里去
  • 本周第一节课已经强调过赋值和复合赋值语句的值是左值。此处再次强调，返回的是变量本身.“引用左操作数”

for的括号里是3个表达式，用分号隔开。 for的循环逻辑：表达式1只执行一次，然后进入表达式2的判断，执行语句序列，再执行表达式3,再回到表达式2的判断。 for循环是当型循环，和while大部分时候都可以互相转换。只有一个情况下逻辑不同：如果语句中含有一句条件下continue;的语句，while会直接去进行运行条件判断，for还会继续执行一句表达式3. for循环适用于已知循环次数的循环，比while可读性高。 for循环省略表达式2,死循环；省略表达式1、3，完全等同于while 如果压行导致for循环没有任何语句序列需要写了，那么for的结尾加个分号，建议换行写成空语句形式，易于理解。 break;只会跳出最近的一层循环/switch。所以说如果想要灵活的跳，就要使用goto语句。 continue;放在switch里会报错。
